# Ratnesh ML Lab

A polished visual index for five reproducible AI/ML projects by **Ratnesh Pratap Singh**, a second-year B.Tech Artificial Intelligence and Machine Learning student at IIST Indore.

## Live demo

**Vercel production URL:** [ratnesh-ml-brwn1i9o5-ratnezhsingh-6317.vercel.app](https://ratnesh-ml-brwn1i9o5-ratnezhsingh-6317.vercel.app)

The interface uses a restrained black/white/blue system with alternating editorial bands, pill actions, generous type scale, and responsive project cards. The visual direction is informed by the supplied Apple and Uber design analyses, while the copy and project evidence remain original to this portfolio.

## Design principles

The showcase is intentionally quiet: the interface should help a reviewer find the work, not compete with it. Every project card points to source code, and each repository documents its setup, tests, limitations, and next experiment. The portfolio avoids fabricated benchmark claims and treats reproducibility as part of the design.
